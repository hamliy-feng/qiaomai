# 侨脉家族页资料采集与填充模板

用途：针对一个华侨家族、宗族或可证实的亲属群体，建立家族主档、2–3 代世系、祖籍、迁徙和相关档案。

# 1. 家族页需要什么

最终页面需要：
- 左侧家族列表。
- 家族主档。
- 家族合影/祖屋/宗祠图。
- 2–3 代家族世系图。
- 核心成员。
- 祖籍与迁徙。
- 关联地点。
- 相关档案/侨批。

# 2. 家族主档字段

| 字段 | 必填 | 说明 |
|---|---|---|
| family_id | 是 | 稳定 ID |
| family_name | 是 | 如“陈氏家族” |
| surname | 是 | 陈 |
| branch_name | 否 | 某房/某支 |
| ancestral_place_id | 建议 | 祖籍地 |
| origin_note | 是 | 50–100 字 |
| migration_regions | 建议 | 东南亚/北美等 |
| active_period | 否 | 大致年代 |
| key_member_ids | 是 | 3–8 人 |
| hero_image_id | 强烈建议 | 合影/祖屋/宗祠 |
| archive_ids | 建议 | 族谱、侨批、契约等 |
| review_status | 是 | 状态 |

# 3. 搜索关键词

- “姓氏 + 家族 + 地名”
- “人物名 + 家族”
- “人物名 + 父亲 / 子女 / 兄弟”
- “姓氏 + 族谱 + 地名”
- “姓氏 + 宗祠 + 地名”
- “姓氏 + 家谱 + 南洋”
- “姓氏 + 侨批”
- “村名 + 族谱”
- “人物名 + genealogy / family”
- “人物英文名 + family”

# 4. 世系图数据

世系图中每个节点必须是 Person，不直接在 SVG 写死名字。

节点字段：
- person_id
- display_name
- birth_year
- death_year
- portrait_image_id
- generation_no
- relation_note

关系边：
- parent_child
- spouse

不要将“堂兄”“宗亲”“同姓同乡”画进直系世系线。可作为 extended_relation 另存。

# 5. 家族关系证据优先级

高：
- 族谱原件。
- 官方人物档案。
- 家族捐赠档案。
- 墓志、婚姻/出生记录。
- 有页码的学术研究。

中：
- 权威人物传记。
- 大学纪念馆。
- 博物馆介绍。
- Wikipedia 有明确来源条目。

低：
- 百度百科。
- 未注明出处的家谱网站。
- 自媒体文章。

低级来源发现的亲缘必须候选化。

# 6. 迁徙资料

家族页的“迁徙”不是把所有成员轨迹叠一起，而是提炼关键线路。

每条迁徙线：
- route_id
- family_id
- from_place_id
- to_place_id
- period
- key_person_ids
- reason_or_context
- source_ids
- certainty

推荐只展示 3–6 条主路线。

# 7. 图片要求

主档图片优先：
1. 家族合影。
2. 祖屋/宗祠。
3. 族谱封面。
4. 家族重要建筑。
5. 多位核心成员合照。

家族合影：
- 16:9 或 3:2。
- 至少 1200px 宽。
- 保留人物完整头部。
- 可做轻 sepia。

祖屋/宗祠背景：
- 16:9。
- 页面右侧做淡化背景，opacity 12–20%。

# 8. 相关档案类型

至少主动搜索：
- 族谱。
- 侨批。
- 出洋名册。
- 商业合约。
- 遗嘱。
- 房契/地契。
- 学校/商会捐款记录。
- 合影。
- 墓碑/纪念册。

# 10. 家族完成验收

- [ ] 家族不是仅因同姓被拼在一起。
- [ ] 至少形成一组可证实的 2 代关系；若不能则不画树。
- [ ] 所有父母/子女/配偶边都有来源。
- [ ] 有祖籍地点。
- [ ] 有 2–5 位核心人物。
- [ ] 有至少一项家族档案或明确标“暂无”。
- [ ] 有主图或统一空图。
- [ ] 迁徙路线不使用无依据精确年份。
