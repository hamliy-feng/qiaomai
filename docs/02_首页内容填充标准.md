# 侨脉首页内容填充标准

用途：首页不是独立采集一套数据，而是从人物、家族、地点、事件、组织、档案、侨批中挑选高质量对象并形成总览。

# 1. 首页需要哪些内容

对应最终首页设计，需要：
- Hero 标题与一句定位。
- 全库搜索。
- 7 类统计数字。
- 7 类核心入口卡。
- 杰出人物 3–6 个。
- 档案与侨批 3–6 条。
- 侨民迁徙地图 3–8 条主路线。
- 快捷标签 5–7 个。

# 2. 首页不单独造数据

所有数字必须由数据库聚合：
- 人物数 = reviewed/published Person 数。
- 家族数 = reviewed Family 数。
- 地点数 = reviewed Place 数。
- 事件数 = reviewed Event 数。
- 组织数 = reviewed Organization 数。
- 档案数 = reviewed Document 数。
- 侨批数 = reviewed Qiaopi 数。

不允许手工在首页写“6,218 人物”之类数字，除非后端真实统计就是该值。

# 3. 杰出人物选取标准

每位人物满足：
- 有合格肖像。
- 有 3 条以上事件。
- 有 2 类以上关联对象，如地点+组织。
- 有至少 1 份档案/来源。
- 页面资料完成度为 Complete。

首页人物卡字段：
- person_id
- display_name
- portrait_image_id
- primary_identity
- years
- featured_rank
- featured_reason（20–40 字，仅后台可用）

前端显示只需要：
- 照片。
- 姓名。
- 身份标签。
- 生卒。

# 4. 档案与侨批选取标准

优先选择：
- 图像质量好。
- 有明确年代。
- 与首页人物/地点有关联。
- 类型多样：侨批、书信、名册、报刊、照片等。
- 版权/展示权限清晰。

首页档案卡：
- document_id / qiaopi_id
- cover_image_id
- title
- type
- year
- featured_rank

# 5. 七类入口卡图片

人物：代表人物肖像。  
家族：家族合影/族谱。  
地点：侨乡建筑/港口。  
事件：群体活动/重要历史照片。  
组织：会馆/学校/商会建筑。  
历史档案：文书/报刊/档案盒。  
侨批：信件/汇款凭据。

入口卡图片必须能明确代表类别，不用抽象插画。

# 6. Hero 图片采集

建议准备固定 3–5 张：
- 广东/福建侨乡旧照。
- 南洋/新加坡历史港口。
- 侨批原件。
- 邮戳/邮票。
- 海外华侨群体照。

合成方式：
- 右侧主要照片 1 张。
- 侨批/邮戳叠加 1–2 张。
- 不超过 4 层。
- 每张图片都要有 source metadata。

# 7. 首页迁徙路线

只展示数据库中证据较完整的代表路线。

字段：
- route_id
- from_place_id
- to_place_id
- person_count
- event_count
- representative_person_ids
- period
- source_basis

建议路线：
- 广东 → 东南亚。
- 福建 → 新加坡。
- 广东 → 北美。
- 福建 → 东南亚。
- 其他根据真实数据决定。

路线不是历史结论文章，只是数据库聚合结果。

# 8. 快捷标签

只能从真实高频标签生成：
- 广东。
- 福建。
- 南洋。
- 新加坡。
- 侨批。
- 家族。
- 华商。

后端未来可以按点击量/数据量自动选。

# 9. 首页内容验收

- [ ] 统计全部来自真实数据库。
- [ ] 7 类入口均有真实对象。
- [ ] 首页人物都是资料完整对象。
- [ ] 首页档案图片许可清晰。
- [ ] Hero 图片都有来源记录。
- [ ] 地图路线由真实地点关系聚合，不手绘假路线。
- [ ] 首页没有长解释文本。
