# 侨脉九页 Web 设计系统与布局执行规范

状态：最终视觉基准  
适用目录：D:\APP\侨脉\frontend  
视觉依据：用户确认的 9 张侨脉成品设计图  
目标：最终网站尽量复现九张参考图的布局、比例、配色和信息密度，同时保证是真正可编码、可响应式、可离线打包、可接后端的 Web，不做只能存在于效果图中的装饰界面。

# 1. 九张页面基准

九张参考图均约为 1672 × 941、16:9 桌面 Web 画布。开发时不把 1672px 写死，而是按这一比例构建。

| 页面 | 视觉基准 | 页面任务 |
|---|---|---|

| 人物 | 侨脉人物_陈嘉庚生平档案.png | 人物目录、人物主档、时间线、关联对象 |
| 家族 | 侨脉陈氏家族档案界面.png | 家族目录、主档、世系树、迁徙与档案 |
| 地点 | 侨脉地点_华侨足迹地图.png | 地点分类、世界地图、地点主档、对象聚合 |

执行原则：
- 九张图是最终产品格局，不再作为“灵感图”。
- 参考图决定区域比例、图片位置、模块次序、卡片密度和视觉语言。
- CSS 尺寸以本文给出的 Web 实施值为准。
- 文字密度要比当前第一版减少：大标题、短标签、短摘要，详细解释藏到详情或展开区域。
- 所有地图、家族树、关系图都必须是真实 HTML/SVG/ECharts，可点击、可接数据，不使用一张静态设计图冒充交互模块。

# 2. 全局画布和栅格

桌面最大内容宽度：1536px。  
1672px 视口时左右约 68px 留白；1440px 时左右至少 32px；1920px 时内容居中。

基础值：
- 顶部导航高度：62px。
- 页面左右 gutter：桌面 32–40px。
- 模块 gap：16px。
- 卡片圆角：12–14px。
- 大卡内边距：20–24px。
- 小卡内边距：12–16px。
- 主要区块上下间距：24–32px。
- 内容使用 12 栏 CSS Grid。
- 参考桌面布局主要在 1440–1920px 范围验收。

断点：
- 1440px 以上：完整九图布局。
- 1200–1439px：压缩图片和卡片，不改变主要分栏逻辑。
- 900–1199px：左侧目录折叠为顶部筛选或抽屉，主体改双列/单列。
- 900px 以下：移动端重新排版，不强求桌面截图比例。

# 6. 图片和历史影像标准

人物肖像：
- 比例 4:5。
- 原图建议至少 800×1000px。
- 胸像或半身，面部位于上 40%。
- 暖历史感：grayscale 40%、sepia 28%、saturate 72%、contrast 96%、brightness 104%。
- 卡片内图片本身不降透明度。
- 只在背景拼贴时降低 opacity。

地点/建筑图：
- 比例 16:9 或 4:3。
- 原图建议至少 1200×800。
- 不裁掉建筑屋顶和关键标识。
- grayscale 20–45%，sepia 20–35%。
- 对比度 92–100%。

侨批/档案原件：
- 尽量保留纸张、印章、邮票原色。
- grayscale 不高于 10%，sepia 不高于 15%。
- 原件预览背景用 #EFE2C8。
- object-fit 使用 contain，不裁切原文。

Hero 背景：
- 内页高 180–205px，图片占右侧 55–65%。
- 图片 opacity 0.42–0.62。
- 左侧覆盖米白渐变，标题区必须保持清晰。
- 首页 Hero 图片 opacity 0.65–0.78，右侧用港口+侨批固定策展拼贴。
- 装饰文字/邮戳 opacity 0.12–0.22。

无图：
- 使用暖米黄纹理占位。
- 中央 24–32px Lucide 图标。
- 显示“暂无可公开影像”。
- 不用 AI 生成头像冒充历史资料。

# 18. 地图实现规范

为了最终打包：
- ECharts 放在本地 vendor。
- world GeoJSON 存本地。
- 广东/福建需要精细地图时另放中国省级 GeoJSON。
- 不用在线瓦片。

样式：
- 海洋近白。
- 大陆淡米灰。
- 国界极弱。
- 重点区域加深 8–14%。
- 节点白色外圈 + 红褐中心。
- 最大节点 16px，最小 7px。
- Route 使用二次/贝塞尔弧线。
- 没有可靠经纬度的数据不绘制精确点。

# 21. 响应式

1200–1439：
- 左栏压到 26–28%。
- 卡片缩图。
- 大标题减 10–15%。
- 首页七入口可压缩或横向滚动。

900–1199：

- 人物、家族、组织主体单列/双列。
- 历史档案改“筛选抽屉 + 列表 35% + 详情 65%”。

900 以下：
- Hero 背景只保留右上角淡图。
- 大标题约 40px。
- 水平时间线改垂直。
- 地图全宽 16:9。
- 家族树允许横向滚动，不能把节点压成小字。
- 档案/侨批列表和详情不再并排，改为路由切换。

# 22. 最终打包规范

- 禁止依赖 Google Fonts。
- 禁止 CDN Lucide / ECharts。
- vendor 库本地化到 frontend/vendor。
- 图片统一放 frontend/assets/media。
- 每张素材旁边有 source metadata 或统一 media_manifest.json。
- 地图 GeoJSON 放 frontend/assets/geo。
- 图标优先 SVG。
- 页面使用相对路径。
- 不依赖在线地图瓦片。
- 不把任何 API Key 写进前端。
- 静态快照模式无后端时仍可打开，不允许白屏。
- 后端模式通过 config 切换。
