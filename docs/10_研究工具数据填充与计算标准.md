# 侨脉研究工具数据填充与计算标准

用途：规范研究工具页的指标、迁徙地图、样本构成、关系图谱和快捷分析。研究工具不单独人工录入统计数字，全部由已审核数据库计算。

# 1. 页面最终需要

- 4 个指标卡：人物、地点、事件、档案。
- 样本构成条形图。
- 迁徙网络地图。
- 关系图谱。
- 快速分析：人物对比、迁徙路径、侨批分布、组织网络。

# 2. 指标卡

只统计符合公开条件的对象：

人物：
count(Person where review_status in reviewed/published)

地点：
count(Place where reviewed)

事件：
count(Event where reviewed)

档案：
count(Document where reviewed and visibility allowed)

每张指标卡同时保存：
- metric_name
- value
- query_definition
- calculated_at
- data_snapshot

前端只显示 value + 名称，不显示长解释。

# 3. 样本构成

推荐默认 5 项以内：
- 福建人物。
- 广东人物。
- 海外经历人物。
- 侨批记录。
- 组织档案。

每一项必须写清查询逻辑。

例如“福建人物”：
- ancestral_place in 福建
或
- birthplace in 福建
两者不能混成一个口径，必须选择并说明。

# 4. 迁徙网络

数据来自 Migration Event，而不是人物页面文字。

每条路线：
- from_place_id
- to_place_id
- event_count
- person_count
- earliest_date
- latest_date
- representative_event_ids

地图线粗可以按 event_count 映射，但最多 3 档，不做夸张流量图。

# 5. 地图显示规则

只显示：
- 坐标可用。
- from/to 都确认。
- event review_status=reviewed/published。

不显示：
- “南洋”等模糊地理区域的伪精确点。
- 只有文字猜测的路线。
- AI 推断但未审核的迁徙。

# 6. 关系图谱

中心可选择：
- 人物。
- 家族。
- 组织。
- 地点。

一级类别：
- 人物。
- 家族。
- 组织。
- 地点。
- 事件。
- 档案。
- 侨批。

默认只取 importance 最高的 15–24 个节点。

每条边字段：
- source_id
- target_id
- relation_type
- evidence_count
- reviewed
- weight

weight 只影响线宽/排序，不改变事实。

# 7. 人物对比

至少支持比较：
- 生卒。
- 祖籍。
- 侨居地。
- 组织。
- 关键事件。
- 关联档案数。
- 侨批数。

不比较没有统一口径的“影响力分数”。

# 8. 侨批分布

可统计：
- 年代。
- 寄出地。
- 收件地。
- 币种。
- 是否有汇款。
- 关联人物数量。

金额统计：
- 不同币种默认分组。
- 无可靠换算依据不做跨币种总金额。

# 9. 组织网络

可显示：
- 人物—组织 membership。
- 创办关系。
- 任职关系。
- 组织—地点。
- 组织—事件。

默认只展示 reviewed 关系。

# 10. 研究查询快照

任何图表结果建议保存：
- query_id
- query_definition
- filters
- result_count
- calculated_at
- snapshot_version

这样后续数据更新可以解释“为什么今天和上个月数字不同”。

# 11. 研究工具 API 数据结构示例

```json
{
  "metrics": {
    "persons": 0,
    "places": 0,
    "events": 0,
    "documents": 0
  },
  "composition": [
    {"label": "福建人物", "value": 0, "query_id": "q_fujian_people"}
  ],
  "migration_routes": [
    {
      "from_place_id": "",
      "to_place_id": "",
      "person_count": 0,
      "event_count": 0
    }
  ],
  "graph": {
    "nodes": [],
    "edges": []
  },
  "snapshot_version": ""
}
```

# 12. 完成验收

- [ ] 所有数字可由数据库查询重算。
- [ ] 图表无手工写死“好看数字”。
- [ ] 样本口径明确。
- [ ] 地图只使用可靠坐标。
- [ ] 关系图只使用真实对象 ID。
- [ ] 不同币种不直接相加。
- [ ] 未审核候选默认不进入正式研究统计。
