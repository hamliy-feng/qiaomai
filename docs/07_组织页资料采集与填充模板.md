# 侨脉组织页资料采集与填充模板

用途：针对学校、会馆、商会、宗亲会、企业、批局、华侨社团等组织，整理组织主档、核心人物、地点、重要事件、档案与关系网络。

# 1. 组织页最终需要

- 左侧组织目录。
- 组织建筑/历史照片。
- 组织名称和简介。
- 核心人物。
- 关联地点。
- 重要事件。
- 历史档案/侨批。
- 轻量关联网络。

# 2. 组织主档字段

| 字段 | 必填 | 说明 |
|---|---|---|
| org_id | 是 | 稳定 ID |
| canonical_name | 是 | 厦门大学 |
| traditional_name | 否 | 历史繁体 |
| english_name | 建议 | Xiamen University |
| aliases | 建议 | 历史名、旧名、简称 |
| org_type | 是 | 学校/会馆/商会/企业等 |
| founded_date | 建议 | 建立/注册时间 |
| dissolved_date | 否 | 解散/停办 |
| headquarters_place_id | 建议 | 主地点 |
| branch_place_ids | 否 | 分支 |
| founder_person_ids | 建议 | 创办人 |
| key_person_ids | 建议 | 负责人/关键人物 |
| short_summary | 是 | 80–150 字 |
| hero_image_id | 建议 | 建筑/历史图 |
| review_status | 是 | 状态 |

# 4. 搜索关键词模板

基础：
- “组织名 历史”
- “组织名 简介”
- “组织名 成立”
- “组织名 创办人”
- “组织名 大事记”
- “组织名 档案”

人物：
- “组织名 校长 / 会长 / 理事 / 创办人”
- “组织名 + 人物名”
- “组织名 董事”
- “组织名 历届负责人”

地点：
- “组织名 地址”
- “组织名 旧址”
- “组织名 分会”
- “组织名 新加坡 / 福建 / 广东”

档案：
- “组织名 章程”
- “组织名 名册”
- “组织名 会议记录”
- “组织名 报刊”
- “组织名 照片”
- “组织名 侨批”

图片：
- “组织名 old photo”
- “组织名 历史建筑”
- “组织名 Wikimedia Commons”

# 5. 组织—人物关系

关系类型：
- founder
- cofounder
- president
- chairman
- principal
- director
- member
- donor
- employee
- advisor
- trustee

字段：
- org_id
- person_id
- role
- start_date
- end_date
- source_ids
- review_status

前端“核心人物”优先显示 founder + 最高级负责人 + 对组织史最重要者，最多 3–6 人。

# 6. 组织—地点关系

- founded_at
- headquartered_at
- branch_at
- active_at
- relocated_to

不要把人物祖籍地自动变成组织地点。

# 7. 重要事件

至少找：
- 成立。
- 迁址。
- 合并/改名。
- 重要建设。
- 停办/复办。
- 重大捐资。
- 重要会议。
- 与华侨史直接相关的活动。

组织页只展示 4–6 个重点事件。

# 8. 组织档案

主动找：
- 创办章程。
- 捐款名册。
- 理事名册。
- 会议记录。
- 校史/会史。
- 老照片。
- 报刊报道。
- 信件。
- 侨批。
- 建筑图纸。

每份档案必须有 document_id，组织页只引用，不复制一份新文档。

# 9. 组织图片

主 Hero：
- 代表建筑/旧址。
- 16:9。
- 至少 1200px 宽。
- 尽量使用历史图。
- 如果使用现代建筑，应明确 caption“现址/今貌”。

人物卡：
- 使用 Person 已有肖像，不在组织页重复存图。

# 10. 轻关系网络数据

中心：当前组织。  
左：相关人物、地点。  
右：事件、档案。

每类只选：
- 人物 1–3。
- 地点 1–2。
- 事件 1–3。
- 档案 1–3。

字段：
- node_id
- object_type
- object_id
- label
- importance
- relation_type

关系图只是摘要，不代替完整知识图谱。

# 12. 组织完成验收

- [ ] 名称、旧名、别名分开。
- [ ] 成立日期有来源或标不确定。
- [ ] 至少 1 个地点关系。
- [ ] 创办人与普通成员不混淆。
- [ ] 至少 2 个重要事件。
- [ ] 至少 1 份相关档案或明确暂无。
- [ ] 主图有来源、年代/现址说明。
- [ ] 关系网络节点都能点击到实际对象。
