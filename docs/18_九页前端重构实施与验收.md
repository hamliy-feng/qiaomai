## 设计与架构

- 最大内容宽 1536px；导航 62px；纸色、棕金、红褐、宋体标题；移动端重新排版。
- `assets/styles.css` 为入口，导入 `styles/tokens.css`、`base.css`、`components.css`、`layouts.css`、`responsive.css`。
- `assets/app.js` 仅启动；`assets/js/pages/` 按页面拆分。
- 共享组件：`core.js`、`navigation.js`、`map.js`、`graph.js`、`family-tree.js`、`image-viewer.js`。
- 工作台保留原有演示实现，通过 `legacy-app.js` / `legacy-styles.css` 隔离。
- Lucide 0.468.0、ECharts 5.6.0、Natural Earth GeoJSON 和所有展示图片本地化；无运行时 CDN / 在线字体 / 地图瓦片依赖。
- `assets/geo/world.js` 为 GeoJSON 的本地脚本封装，以支持直接 `file://` 打开。

## 原件与事实边界

- 当前演示统计来自数组：人物 6、家族 2、地点 9、事件 9、组织 4、档案 6、侨批 3。
- 九图中的大规模数字、家族亲缘、额外人物及档案图未直接复制成真实数据。
- 五位人物肖像、历史新加坡港口、厦门大学建筑、集美纪念建筑、福建土楼等九份图片均记录来源与许可；页脚可查看署名。
- 缺图显示统一暖色空状态。家族待核亲缘显示虚线与待核节点；家族主档使用的相关地点图片有说明。
- 侨批 `q-001` 和档案 `d-qiaopi-demo` 使用原项目自制 SVG，明确标注“演示影像 · 非历史原件”。
- 正式侨批原件及缩略图要求 `watermark_status=none`、`alteration_status=none`、`crop_status=full_page`、`rights_status=allowed`、`media_state=clean_original`，否则不进入阅读器。
- 正式地图只读取有效 DTO 坐标；固定坐标仅供 Demo 城市级示意。关联线不作为历史航线。
- Backend 服务失败显示可重试错误，不静默回落为 Demo。
