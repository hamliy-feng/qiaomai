# 使用规则

1. Source Registry 只证明“来源存在”，不等于获得其全部内容的复制权。
2. 对 Wikipedia/Commons 必须保留 title、URL、license、作者/贡献者信息或可回查路径。
3. Wikidata 结构化数据按 CC0 采集，但每条高价值事实仍应尽量回到它引用的原始来源。
4. 潮汕侨批数据库、CADAL 等若要求正常注册/授权，使用正常入口；禁止绕过登录、验证码、访问控制和下载限制。
5. 商业出版物可作为目录、书目、家族/地区线索；没有额外许可时不把扫描图和全文批量放入侨脉。
6. 百度百科只做 D 级线索池，家族边、精确金额、精确日期、人物身份合并不得仅凭百度转 reviewed。
7. 每个媒体文件必须单独记录 rights_note。网页可访问不等于图片可再发布。
