# 侨脉侨批页资料采集与填充模板

用途：把侨批从一张扫描图整理为可搜索、可关联、可进入人物/家族/地点/事件数据库的结构化史料。

# 1. 侨批页最终需要

对应最终设计：
- 左侧侨批列表。
- 原件 Viewer。
- 标题。
- 寄出地 → 目的地。
- 日期。
- 汇款金额。
- 转录摘录。
- 结构化字段。
- 关联人物。
- 相关地点。
- 相关档案。
- 由侨批生成的事件。

# 2. 一件侨批的最小主档

| 字段 | 必填 | 说明 |
|---|---|---|
| qiaopi_id | 是 | 稳定 ID |
| title | 是 | 可读标题，不改原档号 |
| archive_number | 强烈建议 | 原档号/批号 |
| document_id | 是 | 同时作为 Document |
| sender_raw | 建议 | 原文寄件人 |
| sender_person_id | 否 | 经确认后关联 |
| recipient_raw | 建议 | 原文收件人 |
| recipient_person_id | 否 | 经确认后关联 |
| sent_date_raw | 建议 | 原日期 |
| sent_date | 建议 | 标准化 |
| sent_from_raw | 建议 | 原地名 |
| sent_from_place_id | 否 | 标准地点 |
| sent_to_raw | 建议 | 原地名 |
| sent_to_place_id | 否 | 标准地点 |
| remittance_amount_raw | 否 | 原金额 |
| currency_raw | 否 | 原币种/单位 |
| language | 建议 | 中文/方言书写说明 |
| carrier | 否 | 批局/银号/邮路 |
| summary | 是 | 60–120 字 |
| rights_note | 是 | 原图权限 |
| review_status | 是 | 状态 |

# 4. 原件组成

一件侨批可能包括：
- 信件正面。
- 信件背面。
- 信封/批封。
- 汇款凭证。
- 附条。
- 邮票/邮戳。
- 批局印章。

每一部分都是 document_page，不能只留一张首页截图。

# 5. OCR 与转录

必须区分：

raw_ocr：
- 机器识别原始结果。
- 可有错误。
- 不直接作为正式全文。

diplomatic_transcription：
- 忠实原文。
- 保留原字、异体字、原有错误和特殊称谓。

normalized_text：
- 为阅读/搜索进行规范化。
- 可以补现代标点。
- 历史地名不直接替换，而应通过实体关联说明。

# 6. 结构化人物

从侨批中提取：
- 发件人。
- 收件人。
- 代笔人。
- 转交人。
- 文中亲属。
- 商号/批局人员。
- 其他被提及人物。

每一个先建立 mention：
- mention_id
- surface_text
- page_id
- bbox / text_offset
- candidate_person_ids
- selected_person_id
- review_status

不能因为名字一样直接绑定已有 Person。

# 7. 结构化地点

提取：
- 寄出地。
- 收件地。
- 发件人侨居地。
- 家乡。
- 文中提及地点。
- 批局地点。

保留原词：
“星洲” → canonical_place=新加坡，但 display_original=星洲。

# 8. 汇款

每笔钱单独记录。

| 字段 | 说明 |
|---|---|
| remittance_id | 唯一 |
| qiaopi_id | 所属侨批 |
| amount_raw | “银伍拾元” |
| amount_value | 50，如可可靠解析 |
| currency_raw | 原币种 |
| currency_normalized | 如能确认 |
| purpose_raw | 家用/学费/建屋等 |
| sender_person_id | 可空 |
| recipient_person_id | 可空 |
| event_id | 对应汇款事件 |
| source_span | 原文位置 |
| review_status | 状态 |

不要擅自换算成今天人民币价值。

# 9. 亲属关系

如果原文写“母亲”“胞兄”等：
- 先记录 kinship_mention。
- 只有能确定具体双方 Person 才建立 family_relation。
- 不确定人物身份时不能自动生成家谱边。

# 10. 侨批事件

可产生：
- correspondence：寄信。
- remittance：汇款。
- intention：计划/请求。
- family_news：家庭消息。
- business_info：商业信息。

“拟回乡”“准备建屋”等必须是 intention，不是已发生事件。

# 11. 图片标准

原件：
- 单边 ≥ 1600px 更好。
- 保留纸张边缘、邮票、印章。
- 不美化到改变原件信息。
- 页面卡片缩略图可以裁到 4:3，但 Viewer 使用完整图。


**侨批媒体硬门禁：**
- 正式 Viewer 只接受 `media_state=clean_original` 的原件。
- 原始来源图片自身带有可见水印、机构覆盖字、宣传字、二维码覆盖正文时，`media_state=external_only`，仅保存来源链接和元数据，不复制到正式前端。
- 禁止通过裁剪、涂抹、模糊、修复、生成式填充、AI inpainting、内容感知填充等方式去除水印或覆盖痕迹。
- 禁止为“看起来更干净”重绘、仿制、重生成侨批原件。
- 禁止裁掉档号、纸张边缘、印章、邮戳、邮票、批局戳记或正文来规避水印。
- 仅允许不改变史料内容的技术处理：无损格式转换、方向校正、整页统一曝光/对比度微调；任何处理均需保留原始文件哈希与派生版本说明。
- 如只有带水印图可访问：页面显示“原件请前往来源机构查看”，前端可使用无版权风险的中性占位，不得自己P掉水印。
- 每页必须记录 `watermark_status / alteration_status / crop_status / source_resolution / media_state / reviewer / reviewed_at`。

Hero：
- 侨批页 Hero 可选原件局部放大+邮票/邮戳。
- opacity 55–70%。
- 不能把难以辨认的原件正文直接放在标题下导致噪声过大。

# 13. 侨批完成验收

- [ ] 原件所有页面/正反面齐全或明确缺页。
- [ ] 批号/档号保留。
- [ ] raw OCR 与人工校勘分开。
- [ ] 发件人/收件人原名保留。
- [ ] 地名保留原词并可关联标准地点。
- [ ] 汇款金额保留原文单位。
- [ ] 计划与已发生事件区分。
- [ ] 亲属称谓未被无依据转换成正式家谱。
- [ ] 原件图片有来源和 rights_note。
- [ ] 至少完成一个“侨批 → 人物/地点/事件”的可回查关联。
