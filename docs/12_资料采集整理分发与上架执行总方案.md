# 1. 最终目标

本工作只负责“真实资料获取 → 结构化拆分 → 前端内容适配 → 入库与链接质检 → 上架”，不重做前端设计。所有数据必须最终能够服务现有七类对象：`person / family / place / org / event / document / qiaopi`，并通过稳定 ID 被人物、家族、地点、事件、组织、历史档案、侨批、研究工具九页共同调用。

数量目标按“候选池大于正式发布量”的方式执行：

| 类型 | 候选池目标 | 正式可发布最低目标 | 计数条件 |
|---|---:|---:|---|
| 人物 | 3000–5000，允许扩至10000 | >=1000 | 至少有稳定姓名、广东/福建关联、来源记录 |
| 组织 | >=80 | >=53 | 名称、类型、地点/地域联系、来源明确 |
| 事件 | >=500 | >=231 | 是可描述的实际动作，有时间/时间范围和来源 |
| 家族 | >=20 | >=10 | 至少存在可证明的2代关系或完整家族档案 |
| 地点 | >=150 | 按前端需要发布 | 标准名、历史名/英文名、行政或空间信息可核 |
| 历史档案 | >=500 | 按关联需要发布 | 有原始页面/档号/机构/权限说明 |
| 侨批 | >=5000件候选 | >=3000件规范化 | 图像可读取或已有可用转录，元数据及来源明确 |

“正式可发布”不等于“字段100%齐全”。达到各页面模板的 Usable/Complete 标准才进入正式统计；Candidate 不计入首页正式数量和研究工具统计。

# 2. 固定四工位流水线

整个项目固定使用四个工位，任何 Agent/人工都不得跳工位直接往前端塞资料。

**工位 A：资料获取员（Research）**  
输入：目标对象或批量来源。  
职责：发现网页、数据库、档案、图片、文献、别名和关系线索。  
只做“找”和“摘录”，不擅自统一人物、不润色史实。  
输出：Source Package。

**工位 B：结构化整理员（Canonicalization）**  
输入：Source Package。  
职责：去重、稳定 ID、简繁/英文名、日期、地点、对象关系、事件拆分、候选实体匹配。  
输出：Canonical Package。

**工位 C：前端内容适配员（Presentation）**  
输入：Canonical Package。  
职责：按 docs/02–10 的长度、图片、卡片、时间线和标签要求生成页面展示字段。允许压缩和改写表达，不允许新增事实。  
输出：Presentation Package。

**工位 D：入库质检员（Validation + Publish）**  
输入：Canonical + Presentation。  
职责：检查 Schema、来源、图片授权、悬挂 ID、重复对象、冲突、字段长度、前端关联；通过后才导入后端/替换 Demo 数据。  
输出：Validation Report + Publish Manifest。

正式链路：

`公开资料 → Source Package → Canonical Package → Presentation Package → Validation → Database/API → Frontend`

# 5. 工位 C 的页面分发规则

**首页**：不单独采资料，只从 reviewed/published 数据聚合。选 3–6 个 Complete 人物、3–6 件高质量档案/侨批、3–8 条有证据迁徙路线，统计全部后端计算。

**人物页**：80–130字摘要；5–10个高价值事件；至少2个地点关系；家族关系逐条带来源；重要组织3–5个；档案/侨批优先展示2–8件；主肖像4:5。

**家族页**：至少2代可证关系；核心成员2–8人；主迁徙路线3–6条；族谱/侨批/契约等档案；家族合影/祖屋/宗祠优先。

**地点页**：标准名、繁体/英文/历史名、行政信息、坐标精度、50–120字摘要；关联人物、组织、事件、档案；模糊地区不造坐标。

**事件页**：标题12–28字；实际发生动作；日期精度与来源一致；参与人物/地点/组织；证据文献至少1项；事件图片不可冒充现场。

**组织页**：组织名/旧名/英文名、类型、成立时间、地点、创办人和核心人物、2+事件、档案、16:9主图；关系网所有节点能跳转。

**历史档案页**：原题/标准题、类型、日期、来源机构、档号、原页面、rights_note、多页图像、原文/规范文本/摘要分开保存。

**侨批页**：批号、全部页面、寄收双方原名、寄收地原词、日期、金额/币种、批局、OCR、忠实转录、规范文本、mentions、remittance、事件。只有图像可读或已有可用文本的记录计入“规范化侨批”正式数量。

**研究工具**：完全从 reviewed/published 数据查询，不人工填统计数字。

# 6. 来源优先级和允许用途

A 级：
- 广东/福建档案馆、国家档案局、UNESCO、政府、博物馆、大学档案/数字人文项目、原始档案。
- 用于关键事实最终确认。

B 级：
- 学术论文、专业数据库、学术专著目录/索引、大学研究项目。
- 用于事件、家族、组织和历史背景复核。

C 级：
- Wikidata、Wikipedia、Wikimedia Commons。
- Wikidata 适合批量种子；Wikipedia 适合线索与可归因文本；Commons 图片逐文件读取 license。

D 级：
- 百度百科、新闻转载、自媒体、博客。
- 仅用于发现姓名、别名、年份、亲属、组织等关键词；高风险事实必须回到 A/B/C。

# 8. 人物批量候选生成规则

批量生成只产生 Candidate，不直接发布。

Wikidata/Wikipedia 候选必须满足“广东/福建联系”至少一项：
- 出生地在广东/福建。
- 祖籍/籍贯明确在广东/福建。
- 父系/家族来源在广东/福建且有来源。
- 被可靠来源描述为粤籍/闽籍华侨、海外华人、移民后裔。

同时至少满足“华侨/海外经历”一项：
- 海外长期居住。
- 海外经商/教育/社团/公益活动。
- 移民/入境记录。
- 海外华人社团任职。
- 侨批寄件/收件/批局相关人物。

排除：
- 只有一次短期出访。
- 仅现代旅游/留学且无侨史研究价值。
- 籍贯无法复核。
- 同名冲突无法分辨。

工作目标不是一次请求抓1万条，而是先生成3000–5000候选，再按完成度审核，保证1000+正式人物。

# 10. 事件生成规则

事件不单独“凭空搜231个”，而从人物、组织、侨批、档案中产生：
- 每个 Complete 人物提取5–10条事件。
- 每个组织至少2条事件。
- 每件合格侨批至少产生 correspondence，具备汇款时可另建 remittance。
- 重复事件按主体、动作、时间、地点、证据进行合并。

因此只要完成1000人物，事件数量自然远超231；但正式事件仍需去重和证据审核。正式目标>=231，内部候选>=500。

# 12. 侨批3000件规范化判定

一件侨批只有同时满足以下条件才计入正式3000：
- qiaopi_id 稳定且不重复。
- 有 source_url / source_institution / archive_number 至少两项可追踪信息。
- 原件至少一页可读取，或来源已提供人工转录/可搜索文本。
- pages 顺序和正反面关系明确，缺页显式标记。
- sender_raw / recipient_raw / sent_date_raw / sent_from_raw / sent_to_raw 能提取多少就保存多少，不编造。
- raw_ocr、diplomatic_transcription、normalized_text 分开。
- 简繁转换只能产生派生文本，不覆盖原始转录。
- rights_note 明确。
- review_status 至少 usable/reviewed 才进入正式统计。

3000件的现实路线：
- 先从潮汕侨批数据库、广东档案机构、福建档案机构建立5000+候选索引。
- 优先选图像清晰、元数据齐全、具有人工录入字段的记录。
- 如果公开数据库需要登录/审核，只在正常授权入口内使用，不绕过访问控制。
- 商业出版物只用作目录和线索，除非另有合法全文/影像使用权限。

# 13. 图片与媒体分发

每张前端正式图片必须有：
image_id / object_id / image_type / source_url / source_name / author / date / license / rights_note / width / height / local_filename / caption / review_status。

前端要求：
- 人物主肖像优先>=800×1000，4:5。
- 地点/建筑主图>=1200×800，16:9或4:3。
- 档案/侨批 Viewer 尽量单边>=1600px，必须 contain，不裁掉印章、邮票、页码。
- 无许可图不复制到本地正式 media；可以仅保留外部来源和“暂无可公开影像”。


**新增侨批原图红线：**
- 正式上架的侨批扫描页必须是来源本身提供的无可见水印完整原件，且未经过内容性修改。
- 带水印、宣传覆盖、二维码压字、明显后期修补、去水印、局部重绘、AI 修复填充、为躲避水印而裁切的图片，全部不得进入正式媒体库。
- 不允许“P掉水印后再使用”；若唯一可访问版本带水印，则仅保留档号、结构化文本、来源 URL，并将图片状态设为 `external_only`。
- 所有侨批媒体进入前端前必须人工视觉复核；自动脚本只能辅助检查尺寸/文件哈希/重复，不能替代人工判断水印和内容篡改。
- 正式媒体验收字段：`watermark_status=none`、`alteration_status=none`、`crop_status=full_page`、`rights_status=allowed`、`media_state=clean_original`。
