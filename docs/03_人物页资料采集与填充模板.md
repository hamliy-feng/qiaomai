# 侨脉人物页资料采集与填充模板

用途：给定一个华侨人物姓名后，按本模板搜索、核实和填写，最终直接支持人物页、家族页、地点页、事件页、组织页、档案页和研究工具。

# 1. 页面必须填出的内容

人物页参考九页设计中的人物成品稿，最终需要：

- 左侧人物列表卡。
- 人物主档。
- 生平时间线。
- 家族关系。
- 关联地点。
- 相关组织。
- 历史档案 / 侨批。
- 人物肖像和相关建筑/地点背景图。

# 2. 人物主档字段

| 字段 | 必填 | 示例/说明 |
|---|---|---|
| person_id | 是 | person_chen_jiageng |
| canonical_name | 是 | 陈嘉庚 |
| traditional_name | 否 | 陳嘉庚 |
| english_names | 强烈建议 | Tan Kah Kee |
| other_aliases | 否 | 字、号、旧名、方言音译 |
| birth_date_raw | 建议 | 原始记载 |
| birth_date | 建议 | 标准化 |
| death_date | 否 | 标准化 |
| birthplace_id | 建议 | 指向 Place |
| ancestral_place_id | 建议 | 祖籍不等于出生地 |
| residence_place_ids | 建议 | 侨居/活动地 |
| occupations | 是 | 实业家、教育家等 |
| identity_tags | 是 | 华侨领袖、慈善家等，最多 4 个 |
| short_summary | 是 | 80–130 字 |
| portrait_image_id | 强烈建议 | 主肖像 |
| hero_background_image_id | 否 | 相关建筑/地点 |
| review_status | 是 | reviewed / candidate |

# 4. 生平事件模板

每个人物至少寻找 5–10 个高价值时间节点，不要把每一年都变事件。

字段：

| 字段 | 说明 |
|---|---|
| event_id | 稳定 ID |
| event_type | 出生/迁徙/求学/经商/创办/任职/捐资/回乡/去世等 |
| title | 12–24 字 |
| date_raw | 来源原文 |
| date_normalized | 标准日期/区间 |
| place_ids | 发生地点 |
| organization_ids | 相关组织 |
| summary | 30–80 字 |
| source_ids | 证据 |
| importance | 1–5 |
| review_status | 状态 |

人物页水平时间线只选 importance 4–5 的 5 个节点，其余进入完整时间线。

# 5. 家族关系模板

每条关系独立记录：

| 字段 | 内容 |
|---|---|
| relation_id | 唯一 |
| person_a_id | 当前人物 |
| relation_type | father / mother / spouse / child / sibling / clan |
| person_b_id | 对方人物 |
| relation_label | 父亲/配偶等 |
| source_ids | 证据 |
| confidence | high / medium / low |
| review_status | reviewed / candidate / disputed |
| note | 是否存在异说 |

家族关系必须优先查族谱、人物传记、官方纪念馆、档案或学术研究。只有百度百科等单一二手来源时，先标 candidate。

# 6. 地点关系模板

区分：
- 出生地。
- 祖籍地。
- 早年居住地。
- 迁入地。
- 侨居地。
- 经商地。
- 办学/公益地。
- 回乡地。
- 去世地。

字段：
- person_id
- place_id
- relation_type
- start_date
- end_date
- evidence_source
- certainty

不要把“祖籍福建”写成“出生于福建”。

# 7. 组织关系模板

每个人物查：
- 创办。
- 共同创办。
- 任职。
- 成员。
- 捐助。
- 校董/理事。
- 商业合作。
- 社团活动。

字段：
- person_id
- org_id
- role
- start_date
- end_date
- relation_summary
- source_ids

前端人物页只显示最重要 3–5 个组织。

# 8. 人物图片标准

必须优先寻找：
1. 标准肖像。
2. 不同年龄时期肖像。
3. 与组织/学校/商号合影。
4. 相关建筑。
5. 手稿/书信。

主肖像：
- 至少 800×1000。
- 4:5。
- 面部清楚。
- 尽量正面或 3/4 侧面。
- 不能用低清截图作为主图。

人物主档背景：
- 与人物最强关联的学校、会馆、祖屋、港口。
- 16:9。
- 页面显示时 opacity 10–18%。

图片数据表：
- image_id
- person_id
- role=portrait/background/archive/group
- date
- source
- license
- caption
- local_path

# 9. 人物摘要写法

80–130 字，固定顺序：

姓名 + 籍贯/出生背景  
→ 海外主要活动地  
→ 最重要身份/事业  
→ 对华侨史/教育/商业/社会的代表性贡献

不写价值夸张词，不堆荣誉称号。

# 11. 人物完成验收

- [ ] 有中文标准名和至少检查过英文/繁体/音译。
- [ ] 生卒、籍贯、出生地没有混淆。
- [ ] 至少 5 条关键事件。
- [ ] 至少 2 个地点关系。
- [ ] 有组织关系则至少核对 1 个来源。
- [ ] 家族关系逐条带来源。
- [ ] 有 1 张合格主肖像或明确无可用图。
- [ ] 有至少 3 个来源，其中至少 1 个 A/B 级来源。
- [ ] 页面四个底部关联区至少有两个可展示内容。
