# 本轮发现的执行约束

1. local1 的 `d-drive` workspace script runner 当前只接受 Node；最初 Python validator 被拒绝后已改成 Node 并成功执行。
2. 广东省档案馆的搜索页面适合做公开元数据索引，但部分直接 URL 会超时，因此索引需要保留“列表已采集 / 详情已核 / 原图已核”三个状态，不可混算。
3. 网页显示 Image 不等于拥有再发布权限；本轮没有批量复制原图。
4. 仅凭题名可结构化寄收双方、地点、日期、金额等明确字段，但不能凭题名生成侨批正文。
5. 前端 Presentation 的 `placeIds/orgIds` 必须是实体 ID；本轮曾发现误放 relation ID，已修正并由 validator 固化检查。
