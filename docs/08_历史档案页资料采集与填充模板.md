# 侨脉历史档案页资料采集与填充模板

用途：整理侨批、族谱、移民记录、报刊、名册、照片、会议记录、商业文书等历史资料，使其既能作为独立档案浏览，也能作为人物、家族、地点、组织、事件的证据来源。

# 1. 历史档案页最终需要

对应最终设计：
- 左侧档案筛选。
- 中间档案列表。
- 右侧档案详情。
- 原件预览。
- 元数据。
- 关联人物。
- 关联地点。
- 相关事件。
- 同类档案。

档案页的核心不是“写简介”，而是“把原件和元数据收完整”。

# 3. 档案主档字段

| 字段 | 必填 | 说明 |
|---|---|---|
| document_id | 是 | 稳定 ID |
| title | 是 | 原题优先 |
| title_normalized | 建议 | 便于检索的标准题名 |
| document_type | 是 | 类型 |
| date_raw | 建议 | 原始日期 |
| date_normalized | 建议 | 标准化 |
| language | 建议 | zh/en/其他 |
| script | 否 | 简/繁/手写等 |
| source_institution | 强烈建议 | 收藏机构 |
| collection_name | 否 | 馆藏集合 |
| archive_number | 否 | 档号 |
| source_url | 强烈建议 | 原页面 |
| rights_note | 是 | 是否可公开原图/下载 |
| page_count | 否 | 页数 |
| summary | 是 | 60–120 字 |
| cover_image_id | 建议 | 列表缩略图 |
| review_status | 是 | 状态 |

# 5. 原件图片采集

每一页/面单独保存：

| 字段 | 说明 |
|---|---|
| page_id | 唯一 |
| document_id | 所属档案 |
| page_no | 页码/正反面 |
| image_id | 图片 |
| width | 原宽 |
| height | 原高 |
| source_url | 原图页面 |
| rights_note | 展示权限 |
| checksum | 本地文件校验值 |
| rotation | 是否需旋转 |
| crop_note | 裁切说明 |

档案页 Viewer 使用原件图，不把 OCR 文本渲染成“假扫描件”。

# 6. 图片质量标准

主 Viewer：
- 最好单边 ≥ 1600px。
- 清晰到能放大看字。
- object-fit: contain。
- 不裁掉边缘、印章、页码、邮票。
- 原件有水印时保留，不做去水印处理。

列表缩略：
- 可从原图自动生成。
- 约 320×240。
- 不另存一份“人工裁掉正文”的图。

# 7. 档案—人物关系

relation_type：
- author
- sender
- recipient
- subject
- mentioned_person
- signer
- owner
- donor
- photographed_person

“提到某人”与“由某人撰写”必须分开。

# 8. 档案—地点关系

- created_at
- sent_from
- sent_to
- published_at
- archive_location
- mentioned_place
- event_place

档案收藏地不等于档案历史发生地。

# 9. 档案—事件关系

例如：
- 某侨批证明一次汇款。
- 某报刊报道组织成立。
- 某会议记录证明人物任职。
- 某移民档案证明入境。

关系字段：
- document_id
- event_id
- evidence_role=support/context/contradict
- locator
- source_quote

# 10. 文字内容

保存三种文本：

1. original_transcription：忠实转录。
2. normalized_text：规范化阅读文本。
3. summary：前端短简介。

不要用 summary 覆盖原文。

# 12. 档案完成验收

- [ ] 有稳定 document_id。
- [ ] 有题名和类型。
- [ ] 收藏机构/来源 URL 尽量齐全。
- [ ] 有明确 rights_note。
- [ ] 原件多页顺序正确。
- [ ] 原图未被强裁切。
- [ ] 至少一个人物/地点/事件关联或明确没有。
- [ ] 事实引用能定位页码/图像。
- [ ] 原文、规范文本、摘要互不覆盖。
