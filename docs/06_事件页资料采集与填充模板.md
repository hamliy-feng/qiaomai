# 侨脉事件页资料采集与填充模板

用途：把人物传记、组织历史、侨批和档案中的关键事实拆成可检索的历史事件。

# 1. 事件页最终需要

- 事件搜索。
- 年代/类型/地点筛选。
- 事件类型时间轴。
- 左侧事件列表。
- 右侧当前事件详情。
- 事件人物。
- 发生地点。
- 相关组织。
- 证据档案。
- 地图/图片。

# 2. 什么才算一个 Event

适合成为事件：
- 出生/死亡。
- 迁徙/出洋/回乡。
- 入境/出境。
- 结婚。
- 创办企业/学校/组织。
- 任职。
- 汇款。
- 捐资。
- 重要社团活动。
- 重要历史会议。
- 重大商业行为。

不适合：
- “陈某是一位爱国华侨”——这是描述，不是事件。
- “陈某很有影响力”——评价，不是事件。

# 3. 事件主档

| 字段 | 必填 | 说明 |
|---|---|---|
| event_id | 是 | 稳定 ID |
| title | 是 | 12–28 字 |
| event_type | 是 | migration/founded/remittance 等 |
| date_raw | 是 | 原始记载 |
| date_start | 建议 | 标准化 |
| date_end | 否 | 区间事件 |
| date_precision | 是 | day/year/range/unknown |
| place_ids | 建议 | 发生地 |
| person_ids | 建议 | 参与人物 |
| org_ids | 否 | 相关组织 |
| document_ids | 是 | 证据 |
| short_summary | 是 | 30–80 字 |
| lead_image_id | 否 | 事件图 |
| importance | 是 | 1–5 |
| review_status | 是 | 状态 |

# 4. 搜索关键词

以人物产生事件：
- “人物名 年谱”
- “人物名 创办”
- “人物名 赴新加坡”
- “人物名 回国”
- “人物名 捐资”
- “人物名 任职”

以组织产生事件：
- “组织名 成立”
- “组织名 创办人”
- “组织名 历史”
- “组织名 大事记”
- “组织名 迁址 / 重建”

以地点产生事件：
- “地点 华侨 大事记”
- “地点 会馆 成立”
- “地点 华侨学校 创办”

以侨批产生事件：
- 汇款。
- 寄出。
- 收取。
- 请求回乡/建屋等——注意计划和实际发生要区分。

# 5. 事件类型标准

推荐枚举：
- birth
- death
- migration
- immigration
- return_home
- marriage
- education
- founded_org
- founded_business
- appointment
- donation
- remittance
- correspondence
- association_activity
- political_social
- other

前端可映射成中文标签。

# 6. 日期处理

原文：
“民国二十一年五月十二日”

存：
- date_raw=民国二十一年五月十二日
- date_normalized=1932-05-12
- date_precision=day
- conversion_note=民国纪年换算

原文：
“20世纪30年代”

存：
- date_label=20世纪30年代
- date_start=1930
- date_end=1939
- precision=decade

# 7. 事件地点

每个事件可以有：
- primary_place_id
- from_place_id
- to_place_id
- additional_place_ids

迁徙事件必须区分 from/to。

# 8. 事件图片

优先级：
1. 事件现场照。
2. 同时期人物/组织照片。
3. 相关建筑。
4. 原始档案。
5. 没有就统一空图。

不能拿几十年后的现代建筑照伪装“事件现场”。

# 10. 事件完成验收

- [ ] 标题描述一个实际发生的动作。
- [ ] 日期精度与来源一致。
- [ ] 有至少一个证据来源。
- [ ] 参与人物/组织不靠推测增加。
- [ ] 迁徙事件有 from/to 区分。
- [ ] “计划去某地”不写成“已迁居”。
- [ ] 图片与事件年代关系有说明。
