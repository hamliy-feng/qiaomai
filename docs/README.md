## 使用顺序

前端设计/施工：
00 → 九张参考图 → 页面实现 → 视觉验收。

资料采集：
01 → 选择对应对象模板（02–10）→ 11 交给 Agent 执行 → 人工审核 → 入库 → 前端展示。

## 强约束

- 九张用户确认的成品图是最终视觉目标。
- 旧 D:\BaiduNetdiskDownload\华侨志 只读，不写入。
- 新项目所有新增文件只写 D:\APP\侨脉。
- 数据采集不得只交一篇百科文章，必须拆成对象、字段、关系、来源和图片。
- 未确认内容必须标 candidate，不得伪装为史实。
