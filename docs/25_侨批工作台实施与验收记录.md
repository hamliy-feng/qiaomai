# 侨批工作台实施与验收记录

日期：2026-10-08。依据：用户要求执行docs/24方案。实施范围仅为研究工具与侨批工作台，不夹带其他页面和数据采集工作。

## 已实现

- `research.html`增加研究分析/侨批工作台标签和快捷入口，直达`research.html?tool=qiaopi`。标签切换保留当前图片、原文和转译。
- `qiaopi-workbench.html`复用同一组件，停止加载legacy固定OCR文本。指定ID精确读取；无效ID明确空态，不回退第一件侨批。
- 左栏单图上传、拖放、真实格式检查、20MB与4000万像素限制；原图居中完整适应、缩放、90°旋转与全屏查看。操作不改原文件像素。
- 右栏同时显示可编辑原文和白话转译；原文校订后标记旧转译，原始机器识别文字单独保留；重新转译前确认用户编辑，并保留最多5个旧版本。
- IndexedDB显式本地草稿（含原图）、刷新恢复提示、复制、TXT/JSON下载。JSON分开保留raw_ocr、diplomatic_transcription和modern_translation；未生成规范化正文时normalized_text为null，不把校订正文冒充规范化结果。
- 更换图片/清空/取消任务使用请求版本与AbortController，旧任务晚返回不覆盖新图；识别失败不返回固定示例，转译失败保留成功原文。
- 宽度1024以上双栏，以下纵排；手机文本随页面展开，图片适应时无内部额外横向滚动。
- 服务适配器统一放在`QM_REPO.workbench`，配置仅为公开HTTPS地址；供应商凭据不进入前端。
