# 侨脉地点页资料采集与填充模板

用途：针对一个侨乡、港口、城市、国家或历史地名，整理标准地名、历史别名、地理位置、华侨人物、事件、组织和档案。

# 1. 地点页最终需要

- 左侧地点目录。
- 地点标准名与历史名。
- 世界/区域地图位置。
- 代表性历史图片。
- 地点标签。
- 关联人物。
- 相关事件。
- 相关组织。
- 底部重要地点卡。

# 2. 地点主档字段

| 字段 | 必填 | 说明 |
|---|---|---|
| place_id | 是 | 稳定 ID |
| canonical_name | 是 | 新加坡 |
| traditional_name | 否 | 繁体 |
| english_name | 建议 | Singapore |
| historical_names | 强烈建议 | 星洲、新嘉坡等 |
| place_type | 是 | 侨乡/城市/港口/国家 |
| country | 是 | 国家 |
| modern_admin | 建议 | 现代行政区 |
| historical_admin | 否 | 历史行政区 |
| latitude | 条件必填 | 有可靠来源时 |
| longitude | 条件必填 | 有可靠来源时 |
| spatial_precision | 是 | exact/city/county/region |
| short_summary | 是 | 50–120 字 |
| hero_image_id | 建议 | 代表图 |
| review_status | 是 | 状态 |

# 4. 地点别名和历史名

每个别名独立记录：

| 字段 | 说明 |
|---|---|
| place_name_id | 唯一 |
| place_id | 标准地点 |
| name | 星洲 |
| language | zh |
| script | hans/hant/latin |
| name_type | historical/common/official/romanization |
| valid_from | 如可知 |
| valid_to | 如可知 |
| source_ids | 来源 |

前端搜索必须让“星洲”命中“新加坡”，但详情仍展示原历史名。

# 5. 地理坐标

坐标必须有来源。
- 城市：使用城市中心点即可，precision=city。
- 村落：只有确切位置时用 exact/village。
- 历史地域：“南洋”等不应硬填单点坐标。
- 历史行政区边界不清时用 region。

地图上不得因为想画路线而伪造经纬度。

# 6. 地点—人物关系

每个地点主动找：
- 出生人物。
- 祖籍人物。
- 侨居人物。
- 经商人物。
- 创办学校/组织人物。
- 回乡人物。

关系字段：
- place_id
- person_id
- relation_type
- start/end
- source_ids
- certainty

# 7. 地点—事件关系

事件类型：
- 出生。
- 迁入/迁出。
- 入境。
- 成立组织。
- 创办学校。
- 商业活动。
- 侨批寄出/收取。
- 捐资/公益。
- 回乡。

地点页只显示最重要 3–6 个事件，其余进入事件页。

# 8. 地点—组织关系

寻找：
- 会馆。
- 同乡会。
- 商会。
- 学校。
- 华人企业。
- 侨团。
- 批局/银号。
- 慈善组织。

字段：
- place_id
- org_id
- relation_type=headquarters/branch/founded_at/active_at
- period
- source_ids

# 9. 地点图片

至少寻找：
1. 历史城市/港口全景。
2. 代表建筑。
3. 华人街区/会馆。
4. 老地图。
5. 当地侨批相关地点。

主图：
- 16:9。
- 至少 1200px 宽。
- 建筑/港口清晰。
- 避免现代旅游宣传照作为历史页唯一图片。

底部地点卡：
- 4:3。
- 800×600 以上更好。

# 11. 地点完成验收

- [ ] 标准名、历史名不混写。
- [ ] 经纬度有来源。
- [ ] 至少有 2 个关联人物或明确资料不足。
- [ ] 至少有 1 个事件/组织/档案关联。
- [ ] 有代表图片或空图说明。
- [ ] 历史名称能反向检索到该地点。
- [ ] “南洋”等模糊区域不伪装成精确点。
