# 5. 广东侨批公开档案入口核验

广东省档案馆开放档案查阅系统存在可逐件查看的侨批类别。

已检索页面：
- https://www.da.gd.gov.cn/portal_home/archives?archivesType=41&p=62
- 搜索结果显示：该类别共1549条，共104页。
- 列表直接给档号、题名、成文日期。

逐件详情举例：
- `197-012-00997`：新嘉坡陈绍有寄往潮安上莆区东里乡王应标收的侨批；1940-09-04；公开页面可见3张图。
- `197-012-00671`：吴亚淡寄儿子猛收侨批（内信）；1973-03-28；公开页面可见2张图。
- `G2013-侨批-0159`：公开题名说明为1888年美国开平籍华侨关德宽寄给关廷杰，并随信寄回大鹰银65元；页面可见1张图。
- `G2013-侨批-0173`：新加坡华侨余木金寄给广东潮安县母亲的侨批；页面可见1张图。

广东省档案馆2021年公开信息还说明，当年第三批公开300件，此前两批共600件，说明公开原件本身就是可研究入口。

结论：
- 广东官方开放系统可直接承担至少1549条侨批元数据候选的主要来源。
- 仍需逐件判断图片清晰度、文字可读性、转录可得性和再展示 rights_note。
- 1549 < 3000，因此必须与潮汕侨批数据库及福建来源组合。

- 直接搜索站点依赖 JavaScript。

- 未经确认不绕过登录、验证码或访问限制。

结论：
- 数量上足以覆盖3000。
- 能否成为“规范化3000件”的主来源，取决于正常访问和数据/图像使用条件。
