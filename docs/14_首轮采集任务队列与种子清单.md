# 4. 事件候选生成任务

正式目标>=231，首轮候选>=500。

事件来源分配：
- 1000+正式人物 × 每人至少5个重要节点，理论上产生5000+人物事件候选。
- 53+正式组织 × 每组织至少2个事件，产生106+组织事件候选。
- 3000侨批每件至少有 correspondence，可选产生 remittance；侨批事件用于研究页但需要去重/批量规则。
- 家族迁徙产生 family migration events。

因此“231事件”不单独人工凑数；事件必须从资料事实拆出。

首轮事件模板类别：
- birth
- death
- migration
- immigration
- return_home
- marriage
- education
- founded_org
- founded_business
- appointment
- donation
- remittance
- correspondence
- association_activity
- political_social
- other

第一轮每完成一个人物 source package，立即拆5–10个事件候选；每完成一个组织拆2–6个重要事件。禁止把“人物很有影响力”等评价写成事件。

# 5. 侨批候选与3000规范化任务

正式目标>=3000，候选索引目标>=5000。

来源队列：

**QP-SRC-01 潮汕侨批文献查询统计系统**
- 入口：https://qiaopisjk.sysu.edu.cn/search
- 公开项目信息显示近3万件。
- 已知字段：寄批国家、寄批地、寄批人、收批人、收批地、批面日期、批局、实付款。
- 公开介绍称可查看数字侨批图像。
- 当前动作：确认正常注册/审核、检索方式、是否提供批量导出或学术使用方式。
- 禁止：绕过登录/验证码/访问限制。

**QP-SRC-02 广东省档案馆/广东侨批资料**
- 用途：广东典型侨批、档案号、批局/印章/地名、图鉴样本。
- 广东官方公开数据量远超3000，但逐件数字图像开放程度需核。

**QP-SRC-03 福建省档案馆线上展厅**
- 用途：福建侨批典型记录、家族故事、图像、馆藏信息。
- 先整理公开页面，再确认是否有逐件数据库入口。

**QP-SRC-04 《闽南侨批大全》第一辑**
- 公开书目信息：15册、6000多份。
- 用途：家族/地区/年代/批局候选目录和线索。
- 商业出版物，默认不批量复制全文/图像。
- 若图书馆或合法数字馆藏仅允许阅读，不等于允许前端重新发布。

**QP-SRC-05 CADAL等学术数字馆藏**
- 用途：补充合法可读全文/影像。
- 逐项看访问方式与权限。

规范化每件交付：
- qiaopi.json
- pages.csv
- raw_ocr.txt（若自行OCR）
- diplomatic_transcription.txt（若有人工/可可靠转录）
- normalized_text.txt
- mentions.csv
- remittances.csv
- candidate_links.csv
- sources.csv
- rights_note

判定“可读取/已有繁简文本”：
- A：有高清原件，人工可读，允许OCR；
- B：来源已有人工录入原文；
- C：来源已有繁体/简体全文；
- D：只有低清缩略图、无可读正文——只作候选，不计入3000。
